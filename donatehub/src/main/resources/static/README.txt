DonateHub Simple Frontend

This is a plain HTML/CSS/JavaScript frontend. No Node.js, React, or npm is required.

To use it as one Spring Boot application:
1. Copy index.html, style.css and app.js into:
   src/main/resources/static/
2. Run DonateHubApplication in IntelliJ.
3. Open http://localhost:8080

The frontend uses relative API URLs such as /api/drives, /api/donors, /api/recipients, /api/items and /api/distributions.
